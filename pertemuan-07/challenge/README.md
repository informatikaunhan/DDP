# Challenge - Toolkit Diagnostik Rekursif

Lengkapi `starter.cpp`.

Syarat minimal:
1. `jumlahDigit(int n)` memakai rekursi.
2. `terbesar<T>(T a, T b)` memakai function template.
3. Satu lambda mengecek apakah `jumlahDigit` melewati batas.
4. Satu function pointer dipakai melalui `terapkan()`.
5. Minimal 5 data uji, termasuk batas.
6. Bonus: tambahkan `bool debug` untuk menampilkan parameter setiap recursive call.

Batasan: gunakan konsep Pertemuan 1-7; tidak perlu array/vector/class/dynamic allocation.
