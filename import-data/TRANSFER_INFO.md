# Paket impor DDP101

Paket sumber disiapkan sebagai arsip tar.xz berukuran 65.772 byte, berisi 184 berkas. SHA-256: `50121c0590dcaa5f1abf0c5d8e8c37a3d0a2d16db28a2b028ff09e60e23a4927`.
