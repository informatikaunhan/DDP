# Import bahan belajar mandiri

Folder ini digunakan sementara untuk memindahkan paket bahan belajar mandiri DDP101 ke repositori. Paket sumber berisi 14 modul, contoh C++17, latihan, dan satu aset logo bersama. Workflow impor akan mengekstrak paket ke folder pertemuan. Berkas sumber asli dan lisensi yang sudah ada tetap dipertahankan.
